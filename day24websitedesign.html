html

HTML stands for HyperText Markup Language. It is the standard language used to create and structure the skeleton of every website on the internet. It is a markup language—not a programming language—meaning it uses tags to annotate and organize text, images, and multimedia so web browsers know how to display them

CSS

CSS (Cascading Style Sheets) is a stylesheet language used to design and change the appearance of a webpage. While HTML provides the basic structure of a page, CSS provides the presentation, including layouts, colors, fonts, and responsive behaviors.
